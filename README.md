# Демо-блог

Небольшое веб-приложение блога: регистрация и вход пользователей, редактирование профиля, публикация постов в общую ленту.

## Стек

| Технология       | Версия | Назначение                                   |
|------------------|--------|----------------------------------------------|
| Python           | 3.13   | Язык разработки                              |
| FastAPI          | 0.124  | Веб-фреймворк (страницы + JSON API)          |
| Uvicorn          | 0.38   | ASGI-сервер                                  |
| SQLAlchemy       | 2.0    | ORM, работа с базой данных                   |
| SQLite           | —      | База данных (файл `app/blog.db`)             |
| Jinja2           | 3.1    | Шаблоны HTML-страниц                         |
| python-multipart | —      | Парсинг данных HTML-форм                     |
| python-dotenv    | —      | Загрузка конфигурации из `.env`              |

## Установка и запуск

1. Установите зависимости:

   ```bash
   python -m pip install fastapi "uvicorn[standard]" sqlalchemy jinja2 python-multipart python-dotenv
   ```

2. Создайте файл конфигурации из примера:

   ```bash
   cp .env.example .env   # Linux/macOS
   copy .env.example .env # Windows
   ```

3. Запустите приложение:

   ```bash
   python -m app.main
   ```

4. Откройте в браузере: <http://127.0.0.1:8000/>

Альтернативный запуск через uvicorn напрямую (без учёта `.env` для адреса):

```bash
python -m uvicorn app.main:app --reload
```

## Возможности

- **Регистрация** (`/register`) — username (3–32 символа, буквы/цифры/`_`/`-`), email, пароль (от 6 символов). Username и email уникальны.
- **Вход / выход** (`/login`, `/logout`) — сессия на основе cookie (SessionMiddleware).
- **Профиль** (`/profile`) — просмотр и изменение username, email и пароля (пустое поле пароля — без изменений).
- **Новый пост** (`/posts/new`) — отдельная страница, доступна только авторизованным пользователям; пост сразу появляется в ленте.
- **Лента** (`/`) — все посты сообщества, загружаются через API.
- **Страница поста** (`/posts/{id}`) — пост и его комментарии.
- **Комментарии** (`/posts/{id}/comments`) — оставлять комментарии могут только авторизованные пользователи.

## API

Базовый URL: `http://127.0.0.1:8000`

Авторизация выполняется через **сессионный cookie** (`session`). Чтобы получить cookie в Postman:
1. Убедитесь, что в Postman включён **Cookie Jar** (по умолчанию включён).
2. Выполните `POST /login` с данными пользователя — cookie сохранится автоматически.
3. Все последующие запросы, требующие авторизации, будут использовать этот cookie.

---

### GET /api/health

Проверка работоспособности сервера.

- **Авторизация:** не требуется
- **Тело запроса:** нет

**Пример ответа `200 OK`:**
```json
{"status": "ok"}
```

---

### GET /api/posts

Получить список всех постов (от новых к старым).

- **Авторизация:** не требуется
- **Тело запроса:** нет

**Пример ответа `200 OK`:**
```json
[
  {
    "id": 1,
    "title": "Первый пост",
    "content": "Содержимое поста",
    "author": "maga"
  }
]
```

---

### POST /api/posts

Создать новый пост.

- **Авторизация:** требуется (cookie `session`)
- **Content-Type:** `application/x-www-form-urlencoded`

**Параметры тела запроса (form-data или x-www-form-urlencoded):**

| Поле      | Тип    | Обязательно | Описание          |
|-----------|--------|-------------|-------------------|
| `title`   | string | да          | Заголовок поста   |
| `content` | string | да          | Содержимое поста  |

**Пример ответа `200 OK`:**
```json
{
  "id": 2,
  "title": "Мой пост",
  "content": "Текст поста",
  "author": "maga"
}
```

**Ошибки:**
- `401 Unauthorized` — пользователь не авторизован

---

### GET /api/posts/{id}/comments

Получить список комментариев к посту.

- **Авторизация:** не требуется
- **Параметры пути:** `id` — числовой идентификатор поста

**Пример запроса:** `GET /api/posts/1/comments`

**Пример ответа `200 OK`:**
```json
[
  {
    "id": 1,
    "post_id": 1,
    "author": "maga123",
    "content": "Отличный пост!",
    "created_at": "2024-01-01T12:00:00"
  }
]
```

---

### POST /api/posts/{id}/comments

Добавить комментарий к посту.

- **Авторизация:** требуется (cookie `session`)
- **Параметры пути:** `id` — числовой идентификатор поста
- **Content-Type:** `application/x-www-form-urlencoded`

**Параметры тела запроса:**

| Поле      | Тип    | Обязательно | Описание              |
|-----------|--------|-------------|-----------------------|
| `content` | string | да          | Текст комментария     |

**Пример запроса:** `POST /api/posts/1/comments`

**Пример ответа `200 OK`:**
```json
{
  "id": 3,
  "post_id": 1,
  "author": "maga",
  "content": "Спасибо за пост!",
  "created_at": "2024-01-02T10:00:00"
}
```

**Ошибки:**
- `401 Unauthorized` — пользователь не авторизован
- `404 Not Found` — пост не найден

---

### GET /api/profile

Получить данные текущего авторизованного пользователя.

- **Авторизация:** требуется (cookie `session`)
- **Тело запроса:** нет

**Пример ответа `200 OK`:**
```json
{
  "id": 1,
  "username": "maga",
  "email": "maga@mail.ru",
  "secret_note": "Secret note: only authenticated users can see this.",
  "created_at": "2024-01-01T10:00:00"
}
```

**Ошибки:**
- `401 Unauthorized` — пользователь не авторизован

### Вспомогательные эндпоинты для авторизации (HTML-формы)

Эти маршруты возвращают HTML, но их можно использовать в Postman для получения сессионного cookie.

#### POST /login

- **Content-Type:** `application/x-www-form-urlencoded`
- **Тело:** `username=maga&password=secret123`
- При успехе устанавливает cookie `session` и возвращает редирект `302`.

#### POST /register

- **Content-Type:** `application/x-www-form-urlencoded`
- **Тело:** `username=maga&email=maga@mail.ru&password=secret123`
- При успехе создаёт пользователя, устанавливает cookie и возвращает редирект `302`.

## База данных

Используется SQLite, файл `app/blog.db` создаётся автоматически при первом запуске (таблицы `users` и `posts`). Пользователь по умолчанию **не** создаётся — зарегистрируйте первого пользователя самостоятельно через форму `/register`. Пароли хранятся в виде SHA-256 хеша.
