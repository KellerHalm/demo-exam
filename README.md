# Демо-блог

Небольшое веб-приложение блога: регистрация и вход пользователей, редактирование профиля, публикация постов в общую ленту.

## Стек

| Технология       | Версия | Назначение                                   |
|------------------|--------|----------------------------------------------|
| Python           | 3.13   | Язык разработки                              |
| FastAPI          | 0.124  | Веб-фреймворк (страницы + JSON API)          |
| Uvicorn          | 0.38   | ASGI-сервер                                  |
| SQLAlchemy       | 2.0    | ORM, работа с базой данных                   |
| SQLite           | —      | База данных (файл `app/blog.db`)             |
| Jinja2           | 3.1    | Шаблоны HTML-страниц                         |
| python-multipart | —      | Парсинг данных HTML-форм                     |
| python-dotenv    | —      | Загрузка конфигурации из `.env`              |

## Структура проекта

```
demo-exam/
├── .env                    # локальная конфигурация (не коммитится)

    ├── __init__.py

    ├── database.py         # модели SQLAlchemy и функции работы с БД

    │   └── style.css       # стили
    └── templates/

        ├── index.html      # главная страница с лентой постов

        ├── register.html   # регистрация
        ├── profile.html    # профиль и редактирование данных

```

## Установка и запуск

1. Установите зависимости:

   ```bash
   python -m pip install fastapi "uvicorn[standard]" sqlalchemy jinja2 python-multipart python-dotenv
   ```

2. Создайте файл конфигурации из примера:

   ```bash
   cp .env.example .env   # Linux/macOS
   copy .env.example .env # Windows
   ```

3. Запустите приложение:

   ```bash
   python -m app.main
   ```

4. Откройте в браузере: <http://127.0.0.1:8000/>

Альтернативный запуск через uvicorn напрямую (без учёта `.env` для адреса):

```bash
python -m uvicorn app.main:app --reload
```

## Конфигурация (.env)

| Переменная | По умолчанию | Описание                  |
|------------|--------------|---------------------------|
| `HOST`     | `127.0.0.1`  | Адрес локального запуска  |
| `PORT`     | `8000`       | Порт локального запуска   |

## Возможности

- **Регистрация** (`/register`) — username (3–32 символа, буквы/цифры/`_`/`-`), email, пароль (от 6 символов). Username и email уникальны.
- **Вход / выход** (`/login`, `/logout`) — сессия на основе cookie (SessionMiddleware).
- **Профиль** (`/profile`) — просмотр и изменение username, email и пароля (пустое поле пароля — без изменений).
- **Новый пост** (`/posts/new`) — отдельная страница, доступна только авторизованным пользователям; пост сразу появляется в ленте.
- **Лента** (`/`) — все посты сообщества, загружаются через API.

## API

| Метод | Путь            | Описание                                  | Авторизация |
|-------|-----------------|-------------------------------------------|-------------|
| GET   | `/api/health`   | Проверка работоспособности                | нет         |
| GET   | `/api/posts`    | Список всех постов                        | нет         |
| POST  | `/api/posts`    | Создать пост (form: `title`, `content`)   | нужна       |
| GET   | `/api/profile`  | Данные текущего пользователя              | нужна       |

## База данных

Используется SQLite, файл `app/blog.db` создаётся автоматически при первом запуске (таблицы `users` и `posts`). Пользователь по умолчанию **не** создаётся — зарегистрируйте первого пользователя самостоятельно через форму `/register`. Пароли хранятся в виде SHA-256 хеша.
